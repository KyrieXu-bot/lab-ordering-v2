# 业务员电子签名

此目录存放服务方业务员的电子签名图片。系统始终以所选付款方
`payers.owner_user_id` 对应的业务员为准，不使用当前申请人的身份代替。

图片规范：

- 格式：透明背景 PNG。
- 文件名：`<user_id>.png`，例如 `YW0001.png`。
- 建议画布：宽 600–1000 px、高 180–350 px；只保留签名字迹并裁掉多余白边。
- 工号只允许字母、数字、下划线和连字符，须与 `users.user_id` 完全一致。

图片放入本目录后不需要改代码。重新打开或更新服务方信息时，网页预览和后续生成的委托单会自动读取对应签名。
